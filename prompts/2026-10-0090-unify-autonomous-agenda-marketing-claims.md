After [the README and positioning update](2026-10-0080-readme-autonomous-agendas-apt-framework.md), make the same proposition consistent across this repository's active public-facing copy: Promptbook is a framework for long-term autonomous management of projects and agendas, organized through Agent–Project–Task. Do not leave the main README describing autonomous agendas while CLI output, generated package pages or sharing metadata still describe a different primary product.

This is a repository-wide copy/source-of-truth task, not a blind global replacement, a new landing-page implementation or a change to agent execution. Preserve accurate subproduct descriptions, actual capabilities and customer-provided branding.
