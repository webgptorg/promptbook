Each version has its own file in format `vX.Y.Z.md` where `X.Y.Z` is the version number.

For example:

-   `v1.0.0.md` contains the changelog for version 1.0.0.
-   `v1.1.0.md` contains the changelog for version 1.1.0.

The current preversion changes are being tracked in the file `_current-preversion.md`.
