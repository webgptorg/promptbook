# Legacy Promptbook 0.114.0-51

Maintenance release of the pre-Reborn Promptbook from `main`.

- Fixed `ptbk coder verify` repeatedly asking about a never-run `[ ]` prompt after “Not done”. The prompt now stays unchanged, its file is skipped for that invocation, and no duplicate `Fix` sections or verification commits are created. Thanks to [@theluckystrike](https://github.com/theluckystrike) for [PR #331](https://github.com/webgptorg/promptbook/pull/331).
- This fixes the loop reported in [#325](https://github.com/webgptorg/promptbook/issues/325). The existing archival behavior for never-run work is unchanged and remains tracked there.
- Legacy packages are published under the npm `legacy` tag. Install this version explicitly with `npm install --global ptbk@0.114.0-51`.

The new engine is being developed in [`reborn/2026-10`](https://github.com/webgptorg/promptbook/tree/reborn/2026-10). This legacy release does not replace its npm `latest` tag or port the old coder implementation into Reborn.
