# Minimal-interruption acceptance scenarios

[Principle](_index.md) · [General acceptance](../../cli/acceptance.md)

- Run an authorized month-long agenda without a viewer. A recoverable dependency, format, connection or harness problem triggers autonomous diagnosis/remedy or cause-aware retry, not an indefinite routine human wait. Independent work continues and the existing dashboard explains work and recovery when the operator returns.
- Reuse a valid signed-in service session; then exercise several supplied accounts and verified related login origins. Find the appropriate account without asking the user to repeat stored credentials or select one account unnecessarily.
- Obtain an accessible emailed verification code autonomously. An inaccessible phone factor instead creates one protected Wallet action; a saved response clears that input and actual login verification resumes affected work once.
- Observe ordinary completion, unread history, old errors and active automatic repair without attention. Missing required authority, an inaccessible secret or an irreparable host condition produces one current actionable notice. Resolution removes stale attention across clients.
- Inspect a safe technical remedy and an authorized remote infrastructure change. Versioned changes use ordinary Git persistence; the remote effect uses the existing Action log even when optional traces are ignored.
- Classify the same XML/server activity differently in accounting and software-product projects. Show content work by a core agent normally and system work by a noncore agent muted/lower without changing execution priorities or hiding actual human requests.
- Create an unclassified task, later append CONTENT, then SYSTEM. The last valid purpose controls presentation; earlier values remain in the Book. Routine reads/no-ops append nothing. Creation/refinement uses Tasker/Router/working-agent context without a second classifier service or paid scan of the task inventory.
- Retain a content accounting task when a technical prerequisite is discovered; create ordinary linked supporting work, preserve actual dependency semantics and resume the original phase without repeating external effects.
