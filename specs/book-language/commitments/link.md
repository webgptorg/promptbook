# LINK

[Commitments](_index.md) · [References](../references.md)

**Document:** Agent, task or chat.

`LINK {Other entity name}` adds one directed semantic reference to any of the three Book kinds. Multiple LINK commitments are allowed; the inverse edge is not automatically written. The shared normalized resolver selects exactly one definition. LINK alone never schedules, blocks or authorizes work; use task dependency, agent assignment and chat participation commitments for those meanings.
