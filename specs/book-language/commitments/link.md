# LINK

[Commitments](_index.md) · [References](../references.md)

**Document:** Agent, task or chat.

`LINK {{Other entity name}}` adds one directed semantic reference to any supported Book kind. Multiple LINK commitments are allowed; the inverse edge is not automatically written. The shared normalized resolver selects exactly one definition. Use the full declared name, including ordinary date/time and disambiguation text when present, not the type keyword, filename or an undated title-only guess. Existing single-brace forms retain the compatibility meaning defined by the shared resolver.

LINK alone never schedules, blocks or authorizes work; use task dependency, agent assignment and chat participation commitments for those meanings.
