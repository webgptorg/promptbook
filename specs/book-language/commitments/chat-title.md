# CHAT TITLE

[Commitments](_index.md) · [CHAT](chat.md) · [Chats](../../cli/chats.md)

**Document:** Chat.

`CHAT TITLE <title>` supplies a nonempty single-line human-facing topic title. Append it again as the topic evolves: the latest valid commitment wins. Preserve earlier values and chronology rather than rewriting them.

This is presentation metadata. The opening CHAT name remains global reference identity, including creation text. A title update never renames the Book, refreshes its date, changes its filename or requires relinking tasks. Without a title, display the declared name. Literal text within a message is never an effective title commitment.
