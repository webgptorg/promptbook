# CLOSED

[Commitments](_index.md) · [Syntax](../syntax.md)

**Document:** Agent.

The final declaration prohibits automatic learning changes to this agent. Teacher must honor it even for already queued learning work. It does not prohibit the owner from editing the file. Teacher's own Book must explicitly end with CLOSED. OPEN and CLOSED must not conflict.

This is also an [anchoring boundary](../../concepts/anchoring.md): automatic repair/template reconciliation cannot use a different path to change the protected meaning. Deterministic format migration may preserve that meaning without authorizing new instructions.
