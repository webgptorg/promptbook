# TASK NOTE

[Commitments](_index.md) · [Syntax](../syntax.md)

**Document:** Task.

Stores explanatory task metadata, such as an assignment decision, completion evidence, interpreted priority or known occurrence details. It is not an executable condition and must not override routing or completion. Preserve it when other commitments are updated.

Executable amendments use [TASK CHANGE](task-change.md), not an explanatory note. TASK NOTE may explain origin/outcome, but saving it is not proof that a session received or applied instructions. Preserve earlier notes and event history.
