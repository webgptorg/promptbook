# TASK ID

[Commitments](_index.md) · [Syntax](../syntax.md)

**Document:** Task.

Provides a stable reference key, distinct from the display title and commit subject. Engine/authoring operations may generate it when needed, without forcing the user to name tasks uniquely. Duplicate explicit IDs are an error for the affected definitions. Read-only inspection never creates IDs. See [references](../references.md).
