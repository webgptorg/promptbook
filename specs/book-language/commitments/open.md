# OPEN

[Commitments](_index.md) · [Syntax](../syntax.md)

**Document:** Agent.

The final declaration permits learning; omission has the same default meaning. `OPEN` alone allows ordinary permitted learning. Its optional natural-language body limits that learning, for example new knowledge but no rule changes. These limits bind Teacher and are not permission to rewrite themselves. See [learning](../../agents/learning.md).
