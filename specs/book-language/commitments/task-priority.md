# TASK PRIORITY

[Commitments](_index.md) · [Syntax](../syntax.md)

**Document:** Task.

Accepts a nonnegative number or a natural-language description of importance. Higher numeric values run first; absence means ordinary priority zero. Interpret textual importance consistently and expose its effective rank. If interpretation requires Manager, create an ordinary planning/assignment task and preserve the original wording when recording its resolution. Read-only views report unresolved priority without calling a model. Dependencies and earliest-start constraints still apply.
