# Generated Book documentation (historical)

> Historical specification retained from the older Agents Server specs. Language principles remain useful, but old paths, server routes and registry details are not the current ptbk CLI contract; see the [archive policy](_index.md).

[Historical index](_index.md) · [Dictionary](../dictionary.md)

The **Book language** is the domain-specific language in which every agent's source ("book") is written. It is designed to be human-readable while expressing the full behavior of an agent — its "soul". This spec covers the language as the Agents Server consumes it; the authoritative end-user reference is generated by the server itself and served at `GET /api/docs/book-language.md` (with `GET /api/docs/book.md` as a backward-compatible alias). A compatible server MUST serve this documentation, generated from its commitment registry.

## Documentation endpoint

`GET /api/docs/book-language.md` returns the standalone Book-language documentation as `text/markdown`, dynamically generated so it always matches the commitments actually supported by the running server. The docs UI page (`/docs`) renders the same content (see Pages (historical page: `ui/pages.md#documentation`)).
