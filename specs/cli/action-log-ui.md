# Action log page

[External-action records](action-log.md) · [Dashboard pages](dashboard-details.md) · [History](history.md)

Provide a compact **Action log** tile and dedicated terminal/browser page over saved external-action Markdown records, separate from runtime activity, optional traces and Git history. List time, agent, operation/target, outcome and linked task. Open the full record and navigate verified task/evidence/safe receipt links. Failed tasks can have successful actions; partial and uncertain outcomes stay explicit.

Use shared engine-owned readers and ordinary keyboard drill-down, stable selection/scroll/back navigation. Long records/many actions never fill the home tile. Empty prospective history is not a claim that no old external work occurred. All clients share records and actual saved/pending-commit state. Inspection never backfills, retries, calls a provider or creates commits; no second action store, scheduler or approval queue is introduced. Redact secrets before storage/display.

## Acceptance outcomes

Inspect successful/failed/interrupted tasks with traces enabled/disabled, open records and verified links, and preserve selection on arrivals/resize. Report uncertain/missing evidence honestly and never mutate external state through navigation.
